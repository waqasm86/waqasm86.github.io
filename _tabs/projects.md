# Engineering projects

## kaggle-vllm

[`kaggle-vllm`](https://github.com/kaggle-vllm/kaggle-vllm) is the primary project documented here. It is a compatibility and runtime-delivery toolkit for running upstream vLLM in the explicitly validated Kaggle dual-NVIDIA-T4 environment. Its public repository separates runtime provenance, compatibility checks, experiment protocols, and evidence artifacts from narrative claims.

- [Source repository](https://github.com/kaggle-vllm/kaggle-vllm)
- [Documentation](https://github.com/kaggle-vllm/kaggle-vllm/tree/main/docs)
- [Research evidence](https://github.com/kaggle-vllm/kaggle-vllm/tree/main/research)
- [Release history](https://github.com/kaggle-vllm/kaggle-vllm/releases)

> The project wraps and validates upstream vLLM; it is not a fork or a replacement inference engine.
